# Design System

> Status: not started — defined in Phase 01.

Baseline from Phase 00:

- shadcn/ui with the Radix base and Nova preset (`components.json`), CSS-variable theming in
  `src/app/globals.css`.
- Geist Sans / Geist Mono via `next/font`, exposed as `--font-sans` / `--font-geist-mono`.
- Lucide icons.

Target direction (from the brief): white and soft neutral backgrounds, deep navy typography, a
refined indigo/violet accent, consistent spacing, subtle borders and shadows, restrained motion,
accessible contrast and visible focus states.
