# Prompt 01 — Premium Design System

> **Source:** Extracted verbatim from the master prompt supplied on 2026-10-20
> ("PHASE 2 — Premium Design System").

Create a beautiful, polished SaaS invoicing interface.

## Design direction

- White and soft neutral backgrounds.
- Deep navy typography.
- Refined indigo or violet accent color.
- Inter or Geist typography.
- Consistent spacing.
- Elegant borders and subtle shadows.
- Carefully designed forms and tables.
- Restrained animations.
- Clear visual hierarchy.
- Accessible contrast and visible focus states.

Avoid generic-looking dashboards, excessive gradients, random colors, oversized cards, and
unnecessary decorative elements.

## Application layout

Desktop:

- Header with logo, invoice status, and primary actions.
- Invoice editor on the left, approximately 55% width.
- Live invoice preview on the right, approximately 45% width.
- Sticky preview where appropriate.
- Consistent vertical spacing.

Mobile:

- Single-column layout.
- Editor and Preview tabs.
- Responsive tables and forms.
- No horizontal page overflow.
- Touch-friendly actions.

Create reusable UI components and design tokens.

The initial screen should display realistic fictional invoice data rather than an empty interface.

Document the design system and create the phase commit.
