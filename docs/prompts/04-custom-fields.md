# Prompt 04 — Custom Fields

> **Source:** Extracted verbatim from the master prompt supplied on 2026-10-20
> ("PHASE 5 — Custom Fields").

Allow users to:

- Add a custom field.
- Edit the label.
- Edit the value.
- Hide a field.
- Show a field.
- Remove a field.

Example fields:

- Purchase Order Number.
- Project.
- Department.
- Reference.

Only visible fields should appear in the invoice preview and print output.

Custom fields must never affect financial calculations.

Hidden fields must remain hidden even after saving and reloading an invoice.

Add tests or verification where practical. Document and commit.
