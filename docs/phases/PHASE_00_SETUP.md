## Technical decisions

- **Prisma 7.10.1 pinned.** npm's `latest` tag for `prisma` pointed to `8.0.0-rc.23` (a release
  candidate). The prompt requires current _stable_ versions, so 7.10.1 (stable) is used together
  with `@prisma/adapter-better-sqlite3@7.10.1`.
- **`@hookform/resolvers@^5`** instead of v6: v6 declares an optional peer (`effect@^4`) that
  conflicted during install. v5.9.2 supports Zod 4.
- **Zod 4 pinned explicitly** (`zod@^4`); the first install resolved Zod 3 via a transitive dependency.
- **`@types/node@^22`** to match the installed Node.js v22 and satisfy Vitest's peer range.
- **`prisma init` side effects removed.** It created ~200 agent "skill" files in `.agents/`,
  `.claude/`, `.windsurf/` plus `skills-lock.json`, and named the config `prisma7.config.ts`.
  The skill files were deleted (not project code) and the config renamed to the standard
  `prisma.config.ts`.
- **Database file location:** `DATABASE_URL="file:./prisma/dev.db"` (relative to project root).
  Resolution by both CLI and runtime adapter will be verified in Phase 06.
- **Font fix:** shadcn's `globals.css` maps `--font-sans` to itself while the layout defined
  `--font-geist-sans`; the layout now registers Geist as `--font-sans`.
- **`next.config.ts`** generated by create-next-app enables `cacheComponents` and
  `partialPrefetching`; left as generated.
- Unused create-next-app SVGs in `public/` removed.
- `AGENTS.md` (generated by Next.js 16, re-added by `next dev`) is kept and committed, as it
  recommends.
